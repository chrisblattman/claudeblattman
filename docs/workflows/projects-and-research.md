# Project management { #projects-and-research }

Give the project one home and an account of what you're trying to do. That description gives you and your agent something to draw on when writing a proposal or report, deciding what comes next, or preparing for a meeting. The dashboard keeps the immediate work in view.

| Workflow | What it's for |
|---|---|
| **[Set up a project](organize-projects.md)** | Establish the folders, shared context, and instructions you'll use across sessions. |
| **[Clean up an existing project](clean-up-project.md)** | Recover useful work and bring scattered files together. |
| **[Create a project description and dashboard](project-management.md)** | Write the underlying project description and build a dashboard around it. See the [project plan example](examples/research-design-example.md) and [dashboard example](examples/project-overview-example.md). |
| **[Refresh the dashboard and description](weekly-review.md)** | Bring in meeting notes and decisions, update the dashboard, and review suggested changes to the description. |
| **[Prepare for and follow up on meetings](meeting-workflow.md)** | Get ready for a discussion and turn it into decisions and next actions. |

Need to investigate a question? See [Research](research.md). To recover a decision from an old AI conversation, see [Find past work](recall.md).

Track what you've tried in the [project section of the optional checklist](../starter-kit/two-month-plan.md#manage-a-project).

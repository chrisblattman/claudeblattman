# Projects and research

Give recurring work a home, make the current state understandable, and save what the next session needs. Choose the starting point that fits your project.

| Workflow | What it's for |
|---|---|
| **[Set up a project](organize-projects.md)** | Establish local files, shared context, and a way to resume in Claude or Codex. |
| **[Clean up an existing project](clean-up-project.md)** | Recover useful work and reconcile a messy folder without starting over. |
| **[Build a project dashboard](project-management.md)** | Maintain current status and the underlying plan through the project's stages. |
| **[Refresh a dashboard](weekly-review.md)** | Review new evidence for one project, preserving corrections and history. |
| **[Find past work](recall.md)** | Recover decisions and useful material from earlier sessions. |
| **[Deep research](deep-research.md)** | A bounded question, real sources, and checked citations. |
| **[The data analysis workflow](data-analysis.md)** | The agent writes the code, runs it, and you check what came out — *not written yet*. |
| **[Example: project dashboard](examples/project-overview-example.md)** | A fictional overview and meeting log, paired with a substantive project plan. |

Track what you've tried in the [project](../starter-kit/two-month-plan.md#manage-a-project) and [research](../starter-kit/two-month-plan.md#research-a-question) sections of the optional checklist.

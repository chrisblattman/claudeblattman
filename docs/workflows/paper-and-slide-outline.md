# Build a paper and slide deck outline from project notes

*Planned walkthrough. The proposed example is the Bogotá project.*

Start with a project's research notes, meeting records, analysis summaries, and existing figures. Develop an outline for a paper and a companion slide deck, linking each proposed claim to the material that supports it.

The worked example will show how to:

- Extract the main question, argument, and evidence from scattered notes.
- Distinguish results already established from analyses still needed.
- Build a paper outline with a purpose and supporting evidence for each section.
- Adapt that argument into a slide sequence, choosing what the audience needs to see.
- Revise both outlines after the researchers' feedback, keeping unresolved claims visible.

The example still needs the source notes and the actual outline iterations. This page reserves the workflow without presenting it as completed.

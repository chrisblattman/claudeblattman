# Next steps for intermediate and advanced users { #the-two-month-plan }

Start with one useful task, then build on what worked. I've put the quick, widely useful habits first. After that, give one project a home, use it for research and meetings, and work up to routines that run regularly.

The first two stages cover the [homepage essentials](../index.md#my-absolute-essentials-and-where-to-start). If those are already familiar, [start with one ongoing project](#month-two-the-bigger-work). Follow the order when you're unsure what to try next, and skip tasks you've already done or don't need.

This page keeps its own checkmarks in your browser, separate from the homepage.

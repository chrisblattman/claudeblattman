# The two-month plan

A route through most of this site, in an order that builds — each week leans on the one before
it.

**The order matters; the timetable doesn't.** "Week" is a label, not a deadline. Some are half an
hour and some are most of a Saturday, and the times beside each row are rough. Take four months
if that's what your term looks like, or run two in a weekend if you're keen. Nothing breaks.

Tick things off as you go. A week is done when all of its boxes are.

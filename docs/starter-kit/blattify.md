# Blattify — beta testing

You don't have to work through this site on your own. **Blattify helps your AI agent figure out what you're already doing, suggest a useful next step, and walk you through it on a real task.** It uses the essentials and the [Master Checklist](two-month-plan.md), so you can skip familiar practices and spend time on what would help.

!!! note "This skill is in beta"
    We're testing how well it teaches these workflows in different projects and agent setups. [Tell us what worked or where you got stuck](mailto:claudeblattman+feedback@gmail.com?subject=Blattify%20beta%20feedback).

## Install it in the agent you already use

Start with [Claude or Codex on your computer](newcomers.md). You don't need the starter kit or experience installing skills. Ask your agent:

```text
Install the blattify skill from https://github.com/chrisblattman/claudeblattman/tree/main/skills/blattify in this app. Copy the whole folder, including SKILL.md and all its reference files. If I already have it, preserve my customizations and check for duplicate versions.

Tell me when it's ready and whether I need to start a new session to use it.
```

## Try it on your work

Once the skill is available, ask:

```text
/blattify
```

The agent asks which projects to consider and where to keep your shared progress record. It looks at the practices you already use, recommends a useful improvement, and helps you try it. You can also ask for something narrower: “Use Blattify to help me prepare for project meetings.”

As you work, it explains the practice, shows you how to use it, and brings you into the decisions. It saves progress in the place you've chosen so you can return later and pick up where you left off.

You choose what to adopt. Blattify can guide you through installing another skill or connecting an app when needed; it doesn't require setting up everything on this site before you can begin.

[Read the skill's instructions on GitHub](https://github.com/chrisblattman/claudeblattman/tree/main/skills/blattify).

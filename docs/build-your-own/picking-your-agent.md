# Picking your agent

Two companies make the kind of agent this site is about: Anthropic's **Claude** and OpenAI's
**Codex**. Both sit on your desktop (apps like any other), read the files in a folder you point them at, and change
them while you watch. Either will run every workflow here. The choice matters much less than
people expect, and it is reversible — so make it once, quickly, and move on.

The truth is, I pay for and use both daily. A supercharged user should eventually use both, but for now, the choice is not big. 

---

## The short answer

One question settles it: **do you already pay for Claude? Does your company?**

- **Already pay for Claude** (Pro or above, about $20/month) → use **Claude**.
- **Don't** → use **Codex** from OpenAI.

That is the whole rule. If you already pay for ChatGPT and not Claude, invert it. If you pay
for neither, Codex is the usual recommendation — it's my current preferred app, and you can try small tasks with Codex before paying.

Nothing you learn on one is wasted if you later move to the other — the workflows on this site
are the same either way, and the starter kit has a route for both. What does differ is the price
of entry and how much friction you hit installing things, which is what the table below is for.

---

## Claude Code vs Codex

Start with what doesn't change. Both apps put an agent in front of your own files, both will
read a folder and edit what is in it, and neither is better at the actual work. Claims that one
is categorically smarter rarely survive contact with a real task.

What does change, and changes often, is the user interaction and capabilities in each app.

## Pros of choosing Codex

**Deep Research.** The single best reason to have a ChatGPT subscription. Give it a question and it spends 5-30 minutes searching the web, synthesizing multiple sources, and producing a structured report with citations. Claude can do web searches, but they're shallow by comparison. The free ChatGPT plan gives you access to a small number of deep research requests per month, but paying for Codex simultaneously buys you extra deep research requests each month – like a two for one plan. 

**Annotating.** You can open files direclty inside the app, highlight sentences and request changes. Send all your comments at once. 

---

## Pros of choosing Claude

**Everything in the Code tab.** The desktop app that reads your files, manages your email, and runs custom skills has no real ChatGPT equivalent. If you use Claude Code, Claude is your primary AI tool by default.

**Long-form writing and editing.** Claude consistently produces better prose — maintaining voice, following structural instructions, and providing substantive feedback.

**Complex reasoning.** For research design, methodology review, and strategic planning, Claude Opus 4.6 tends to produce more thoughtful output than GPT-4o.

**Projects and persistent context.** Claude.ai's Projects feature lets you create a workspace with instructions and files that persist across conversations — better than ChatGPT's memory system for structured, project-based work.


---

### The bottom line

**If you can only pick one:** Claude, especially if you plan to use Claude Code.

**If you can afford both:** Use Claude as your primary tool and ChatGPT for Deep Research and web-heavy tasks. They're genuinely complementary.

**If you're just starting:** Start with whichever one you already have, then run [your first session](../starter-kit/newcomers.md) — the ten steps there work the same on both.

# External tools I use

An agent is good at working on files you already have. These four are good at the step before
that: getting things *into* a form it can work on.

None is required. Each one removes a specific kind of friction, and I'd add them in roughly this
order.

*As of October 2026.*

## Dictation — Wispr Flow

Speaking is about three times faster than typing, and the thing that makes it worth a page of its
own is that **agents don't mind rambling.** You no longer have to compose a tidy request; you can
talk through what you want the way you'd brief a colleague and let the agent sort it out.

This is the tool I'd add first. It changes how much you bother to say, which changes the quality of
what you get back.

[:octicons-arrow-right-24: Dictation](../essentials/wispr-flow.md)

## Meeting transcription — Granola

Records the meeting, transcribes it, and leaves you a transcript the agent can read. The workflow
that falls out of it is the point: after a call, the agent turns the transcript into the things you
now owe people.

## A research notebook — NotebookLM

Upload a stack of papers and ask questions across all of them at once. It is strongest where
agents are weakest: a very large pile of source documents that you want to interrogate rather than
edit.

[:octicons-arrow-right-24: Gemini Notebook](../essentials/notebooklm.md)

## A reference manager — Zotero

Free, and the standard in most research fields. It holds your citations and PDFs in one library
with a consistent structure, which matters here for one reason: **a well-kept Zotero library is a
folder of PDFs with real metadata**, and that is exactly the kind of input an agent handles well.

You can also connect it directly, so the agent can search your library rather than you exporting
from it. That route is a connector, not something built into the app:

## What I'd skip at the start

Adding tools is the easiest way to feel productive without being productive. Each one is another
subscription, another place your data lives, and another thing to keep working.

The honest order: get an agent working on a real folder first. Add dictation when typing starts
feeling like the bottleneck. Add the others when a specific task keeps failing for want of them —
not before.

# Implemented scope and audited dependency gap

This starter kit implements shared local council instructions, three default persona definitions and optional Chief of Staff, immutable briefs/prompts/reports, native fresh workers, optional requested challenge, fresh synthesis with one declared fallback, and separate review archives.

The audited balanced Light/Full policy is included as reference data, but the portable starter **cannot execute those modes yet**. Their required external runtime was not supplied as a complete portable package: it includes a resolver/validator, model-pinned provider launchers, Gemini through Antigravity, evidence/provenance checks, chair packet verification, and compatible receipts. The public Ask Agents transport has different restrictions and a Gemini CLI route. It is not a compatible substitute.

The archive helper rejects Light/Full before dispatch. A missing dependency does not silently change provider counts or route. Do not claim a private runtime's hash-bound certification for this helper. The two manifest formats are intentionally distinguished by schema identifiers.

Model/catalog changes, below-quorum available-report synthesis, and one-shot synthesis-only recovery require the full audited runtime and further acceptance work. This starter kit preserves substantive reports and labels limitations; it does not invent a portable equivalent of all of that machinery.

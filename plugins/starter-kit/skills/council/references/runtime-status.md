# Runtime and verification status

The public helper supports local personas, exact custom provider seats, Light (one each of Claude/Codex/Gemini) and Full (two each plus challenge). Host instructions orchestrate fresh native workers and the shared external transport; the Python helper freezes inputs and records outcomes rather than launching agents itself.

Gemini means Antigravity. Grok is an opt-in custom provider using the pinned official subscription-authenticated CLI. Claude and Codex are the supported host apps. A connected provider is not automatically a supported host: Gemini/Antigravity/Grok native host packages are not included.

This is a portable adaptation, not a certified copy of a private multi-provider runtime. All chairs use fresh native host workers. Execution/source/model limits are reported. Offline acceptance tests do not establish live provider availability. See the release validation notes for checks actually performed.

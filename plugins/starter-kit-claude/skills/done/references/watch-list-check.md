# Optional retrospective

Run only for an explicit `retro` request. Use the user's configured watch list, or `working-notes/watch-list.md` in the current project. Do not assume a private global tips folder exists.

Review unresolved hypotheses, failed approaches, repeated friction and near-misses from this session. Match observations to existing entries by specific topic and evidence. Add or update at most five entries with Observation, Context, Count, First observed, Last seen, Sessions (capture IDs) and Possible next step. A retry with the same capture ID must not increment the count twice.

Preserve Active, Escalated and Dropped sections. At three distinct supporting sessions, surface a concrete improvement proposal and link the evidence. A count is a prompt to investigate, not proof of a general rule or permission to modify a skill. Keep the proposal pending until the user decides; do not silently promote preferences or run a new council.

Save with the same conflict-checked procedure as the other continuity files. Report observations and proposals briefly. This public adaptation does not scan private research catch-all folders or delete artifacts.

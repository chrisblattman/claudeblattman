## Agentic coding for economists

[Aniket's living guide](https://aieconomist.io/guides/agentic-coding-for-economists), October 2026 edition, checked October 24. Its setup examples include October 12–13 observations. The author discloses AI assistance in producing the guide. A later retrieval date does not renew its advice.

- Section 2 distinguishes permission to access files from actually reading their contents. Saving context helps later only when the next session retrieves it.
- The same section illustrates checking a note containing a decision, its reason and an open question, then reading it in a later conversation.
- Sections 3–4 discuss project context and version history for inspecting changes. Particular model, subscription, interface and permission recommendations are dated; verify them before using them now.

These are explanations and illustrative workflows, not comparative effectiveness results.

Auto-captions can contain errors; verify exact disputed wording from the recording.

- [5:41–7:05](https://www.youtube.com/watch?v=BQahybA5lMg&t=341): Aniket reports using sustained questions to understand an AI-assisted document. Easier invocation may encourage practice; no learning effect was measured.
- [20:54–21:16](https://www.youtube.com/watch?v=BQahybA5lMg&t=1254): Repeating work three times is a tentative prompt to consider a skill, especially for newcomers, not a universal threshold.
- [24:39–27:30](https://www.youtube.com/watch?v=BQahybA5lMg&t=1479): One project's cleaning code can remain code; a reusable review of consequential cleaning decisions may suit a skill.
- [49:17–50:23](https://www.youtube.com/watch?v=BQahybA5lMg&t=2957): Revisit instructions after model changes or failures; this does not establish that every older instruction is unnecessary.
- [59:00–1:00:20](https://www.youtube.com/watch?v=BQahybA5lMg&t=3540): Mining earlier corrections for workflow ideas is a proposal he had not yet tried; using meeting transcripts is reported practice.
- [1:06:15–1:07:30](https://www.youtube.com/watch?v=BQahybA5lMg&t=3975): His slide workflow settles content before presentation. It does not establish a universally superior format.

The recording and its captions represent one source, not independent corroboration.

## Applying these sources

The skill's grouping into skills, coordination, context, learning and communication is the maintainers' navigation, not Aniket's ranking. Adapting a practice to a particular user's friction, checking whether it already works, or proposing a trial is the assistant's judgment. Label those applications accordingly. Missing personal evidence means provisional advice, not a diagnosis that the user has no room to improve. Recognize useful existing practices without inventing a new recommendation.

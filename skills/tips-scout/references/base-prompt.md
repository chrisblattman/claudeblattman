# Base AI-workflow scouting prompt

Search X and the web for useful AI-workflow approaches published between [WINDOW_START] and [WINDOW_END]. Focus on practical work with agents, not general AI news. Prefer original sources, concrete examples and approaches people have actually used.

Investigate:
1. Skill and agent architecture: reusable instructions, independent agents, handoffs and evaluation.
2. App features and releases: useful changes in Claude Code, Codex and connected tools.
3. Research and work: writing, evidence gathering, project management and everyday administration.
4. New tools and repositories: useful capabilities, installation requirements and maintenance.
5. Knowledge organization: finding prior work, keeping references useful and avoiding duplicate systems.

Prioritize the coverage gaps and active investigation topics supplied with this prompt. Skip items already covered unless there is a meaningful new version, result or disagreement. Skip unsupported productivity claims, engagement bait and generic tutorials without a concrete application.

For each finding, give the original URL, author, publication date, what it does, evidence of actual use, a practical first step, requirements/costs if established, and limitations. Distinguish firsthand evidence from claims and inference. Group duplicate coverage of the same finding. Say when dates, source access or verification are unavailable; do not fabricate posts, citations or a fixed number of results.

Finish with the most promising ideas to try and the questions that would determine whether they fit. Do not install tools or change any files while researching.

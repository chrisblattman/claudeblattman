# Research synthesis is included

The separate `/dr-synthesize` command is retired in this public library. Both research workflows now include synthesis:

- [Research Council](../research-council/SKILL.md): ordinary research by available AI agents, or synthesis of named saved reports.
- [Deep Research](../deep-research/SKILL.md): actual ChatGPT and Gemini browser Deep Research, including report import and synthesis.

To combine older reports without starting new jobs, ask:

```text
/research-council Synthesize these saved reports without launching new research: [reports]
```

Preserve original reports and any personal customizations when retiring an installed copy. Keep backups outside active skill/command folders. No private installation is changed by this repository migration.

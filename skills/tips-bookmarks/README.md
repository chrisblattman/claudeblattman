# Bookmarks now belong to tips-curate

The separate `tips-bookmarks` skill is retired. Install the entire [tips-curate folder](../tips-curate/), which processes bookmarks, email tips, and saved scout reports through one review and deduplication workflow.

Use `/tips-curate bookmarks` for bookmarks alone, or `/tips-curate` for configured bookmarks and email. A bookmark connection is optional; failure does not block other sources. Preserve your existing bookmark state and customizations when migrating. Do not install this notice as a skill.
